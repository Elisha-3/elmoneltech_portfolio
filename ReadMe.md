# Elisha Keanche — Single-Page Portfolio

A responsive, single-page personal portfolio website built with **Bootstrap 5**, showcasing my best projects, case studies, and contact details. Includes dark mode support and a working contact form via Formspree.

## ✨ Features

* **Responsive design** for desktop, tablet, and mobile
* **Dark/Light theme toggle** with local storage persistence
* **Featured projects** with case studies (Problem → Solution → Tech → Impact)
* **Downloadable CV** link
* **Quick contact form** (Formspree integration)
* **Tech Stack section** with icons
* **Back to top** link in footer

## 🛠️ Tech Stack

* HTML5
* CSS3 (Bootstrap 5)
* JavaScript (Theme toggle, collapse)
* Bootstrap Icons
* Formspree for form handling
